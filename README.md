# Подработка 154

Сервис подработки: вакансии из открытых Telegram-источников + публикация объявлений работодателей. Первый город — Новосибирск.

**Текущий статус:** ветка `render` готова к деплою на Render как тестовый MVP-контур. В этой ветке GitHub Actions уже выполняет `npm install`, `typecheck`, unit-тесты и `next build`.

## Запуск локально

```sh
npm install
npm run typecheck
npm test
npm run build
npm start
```

Используйте Node.js 22.18+ и npm. Секреты не отправляйте в чаты и не коммитьте `.env.local`.

## Что реализовано

- Next.js App Router, React, TypeScript, Tailwind 4.
- Каталог вакансий с поиском, категориями, фильтрами, пагинацией, избранным и сохранёнными поисками.
- Карточки вакансий с реальными контактами и ссылками на 2ГИС/Яндекс.Карты только когда адрес реально указан.
- Supabase Auth, профили работодателей, создание/редактирование вакансий, предпросмотр и модерация.
- Админка: модерация, справочники, источники, цены, лимиты, роли, журналы.
- Публичный Telegram-импорт: открытый канал можно читать без владения каналом и без Telegram Bot API; новые сообщения попадают в разбор и затем в очередь модерации.
- Консервативный парсер: не придумывает адрес, зарплату, дату или контакты и оставляет неизвестные поля пустыми.
- Дедупликация Telegram-вакансий по исходному сообщению.
- PostgreSQL-очередь, worker, автоматическое истечение вакансий.
- Web Push с добровольным включением.
- Sandbox-сценарий платежей для разработки; реальные платежи можно подключить позже.

## Telegram

Первый источник: публичный канал `@rabota154NsK` / `https://t.me/rabota154nsK`.

Импорт вызывается через:

```sh
GET /api/telegram/import-public
```

В Render предусмотрен отдельный cron-процесс:

```text
*/15 * * * *
```

который вызывает этот endpoint с `Authorization: Bearer $CRON_SECRET`.

## Render

Для Render используется ветка `render` и `render.yaml`.

Сервисы Blueprint:

- `podrabotka154` — web service;
- `podrabotka154-telegram-import` — cron для Telegram-импорта каждые 15 минут.

Не рассчитывайте на Vercel production для этого контура: рабочая ветка проекта — `render`.

## Supabase

Основная база текущего тестового контура содержит импортированные Telegram-сообщения и вакансии, которые после разбора проходят ручную модерацию. Публичные RPC импортёра ограничены серверным доступом.
