# Telegram

Первый источник: https://t.me/rabota154NsK. Канал не принадлежит заказчику. Поэтому seed создаёт источник **выключенным**, с адаптером `manual`.

## Ручной импорт, рабочий путь для первого MVP

1. Уточните законное основание использования объявления и контактов, при необходимости согласуйте публикацию с автором/владельцем.
2. В `/admin/telegram` включите источник. Имя пользователя вводится без `@`.
3. Вставьте фактические номер сообщения, дату ISO 8601 и полный оригинальный текст.
4. Сервер сохраняет `telegram_messages`; SQL-триггер атомарно создаёт задание.
5. Отдельный `npm run worker` разбирает текст и отправляет кандидата в модерацию.
6. Администратор сверяет оригинал и поля, затем публикует.

Невакансии остаются в сырых сообщениях и `parser_runs`, не исчезают. Консервативный парсер может пропустить непохожий на вакансию текст; это не LLM и не гарантия полного извлечения. Администратор проверяет исходные сообщения.

## Bot API

Нужен созданный вами бот через https://t.me/BotFather и доступ бота к каналу, предоставленный его владельцем. Использование вашего пользовательского аккаунта не превращает Bot API в доступ к чужой истории.

На общедоступном HTTPS-хостинге задайте `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, `NEXT_PUBLIC_APP_URL`. Затем локально:

```sh
npx tsx --env-file=.env.local scripts/register-telegram.ts
```

В источнике задайте точный `chat_id`, `adapter=bot`, включите источник. Не угадывайте chat_id. Webhook принимает `channel_post`, проверяет секрет заголовка в постоянное время, разрешённый источник и размер сообщения. Изображения из Telegram не скачиваются, caption сохраняется. Повторные deliveries не создают новый оригинал.

Этот путь принимает **новые** сообщения, не историю. `edited_channel_post` и удаления в текущую версию не входят. Требуется отдельная политика синхронизации изменений.

## Альтернативные адаптеры

`TelegramSourceAdapter` определяет `connect`, `disconnect`, `fetchMessages`, `subscribe`, `normalizeMessage`.

- `ManualImportAdapter`: приём явно переданных сообщений.
- `BotApiAdapter`: разрешённый Bot API; polling является альтернативой webhook, не включайте оба режима одновременно.
- MTProto: **не реализован**; интерфейс и env-поля зарезервированы. Если позже он понадобится, настройка начинается с https://my.telegram.org/apps и правил https://core.telegram.org/api/obtaining_api_id. Авторизация, сессия и права должны храниться только в доверенной среде.

Не обходите запреты на пересылку, авторизацию или доступ. Наличие публичной ссылки не означает безусловного права перепубликовывать персональные данные.

## Управление

Редактирование, активация/отключение: `/admin/telegram`. Удаление источника без сообщений: `/admin/sources`. Источник с историей не удаляется, чтобы не потерять происхождение объявлений; его можно выключить. Ошибки обработки и повтор: `/admin/logs`. Исходный текст и результаты разбора доступны администратору.
