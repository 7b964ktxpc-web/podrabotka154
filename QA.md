## Обязательный прогон в своей среде

```sh
npm install
npm run typecheck
npm test
npm run build
npm run start
```

Затем отдельный тестовый Supabase с миграциями и seed. Заполните `TEST_SUPABASE_URL`, `TEST_SUPABASE_ANON_KEY`, `TEST_SUPABASE_SERVICE_ROLE_KEY`, отличные от рабочего проекта:

```sh
npm run test:integration
```

Тест создаёт тестовых пользователей, компанию, вакансии, источник и sandbox-заказы. Они **намеренно остаются в отдельном тестовом проекте** для анализа. После испытаний сбросьте одноразовый проект. Никогда не переносите эти объявления в публичную БД.

Для E2E нужен запущенный тестовый сайт, SMTP либо заранее подтверждённые тестовые аккаунты, опубликованная тестовая вакансия с адресом, профиль работодателя и свободная квота. Заполните E2E-переменные:

```sh
npx playwright install chromium
npm run test:e2e
```

Без указанных аккаунтов некоторые тесты **пропускаются**. Пропущенные проверки не означают успешную приёмку. В E2E переход на 2ГИС перехватывается тестовой заглушкой только для проверки URL/новой вкладки; реальное поведение карты нужно проверить отдельно.

## Ручная приёмка

- [ ] Главная на 360, 390, 768, 1440 px; нет горизонтального скролла.
- [ ] Поиск «грузчик» и категории; «сегодня/завтра» по местной дате; сумма именно за смену.
- [ ] Пустые, ошибочные, loading и недоступные состояния.
- [ ] Регистрация → реальное письмо → callback → кабинет; вход/выход/сброс пароля.
- [ ] Неавторизованный пользователь не получает private data; employer не становится admin.
- [ ] Создание компании, фото, черновик, предпросмотр, отправка, модерация, публикация.
- [ ] Редактирование чужого черновика запрещено через UI и прямой PostgREST.
- [ ] Фаворит сохраняется после перезагрузки; другой аккаунт его не видит.
- [ ] Сохранённый поиск, разрешение Push, новое подходящее объявление, одно уведомление.
- [ ] Контактные кнопки отсутствуют при null; события не блокируют переход.
- [ ] Реальный оригинал Telegram → очередь → parser → moderation → publish; повтор не создаёт дубль.
- [ ] Источник выключается; удаление непустого источника не теряет оригиналы.
- [ ] Цены берутся из БД; подмена суммы и подписи не активирует продукт.
- [ ] Повтор webhook не создаёт второе продвижение; возврат прекращает права.
- [ ] Параллельная отправка вакансий не превышает бесплатную квоту.
- [ ] Истечение скрывает вакансию даже при выключенном worker; после worker статус expired.
- [ ] Sitemap/canonical/robots проверены на фактическом HTTPS-домене.
- [ ] Нет демоданных; юридические страницы и сведения об операторе утверждены.
