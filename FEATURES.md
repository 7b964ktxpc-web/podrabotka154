# Матрица реализации v0.1

«Реализовано» ниже означает наличие исполняемого кода. Интеграционные результаты отсутствуют до запуска пользователем.

| Область | В архиве | Ограничение |
|---|---|---|
| Главная, каталог, фильтры, карточка | SSR, параметры URL, пагинация | Дизайн не проверен браузером |
| Адрес → карты | Единые генераторы, null без адреса | Проверено кодирование, не фактическая выдача внешних карт |
| Supabase Auth | Регистрация/email, вход, сброс пароля, cookies refresh | Требуется SMTP и реальные проверки |
| Избранное | RLS, API, UI, недоступные сохранённые вакансии | Нужен интеграционный прогон |
| Сохранённый поиск | Название, фильтры, флаг уведомлений, удаление | Нет отдельной формы редактирования; можно удалить и сохранить заново |
| Push | Подписка/отписка, очередь, VAPID, дедупликация | Реальный push не отправлялся |
| Профиль работодателя | Владелец редактирует, публичная страница, логотип | Администратор просматривает, отдельного редактора чужой компании нет |
| Размещение | Поля с подсказками, фото, preview, moderation | Не проверено с настоящим Storage |
| Telegram чужого канала | Ручной импорт оригинала | Нет обещания автоматического чтения |
| Telegram своего/доступного канала | Проверяемый webhook, Bot API adapter | Не настроен бот, не проверена доставка |
| Parser | Консервативные правила, сменный интерфейс | Не LLM; даты и сложные поля проверяет человек |
| Дубли | Точный нормализованный fingerprint и все источники | Нечёткие/перефразированные дубли не объединяются |
| Модерация | Публикация/отклонение/черновик/архив | Решение человека обязательно |
| Admin источников | Добавить/изменить/отключить, сырые сообщения, удалить пустой | Источник с оригиналами не удаляется |
| Admin пользователей | Список и изменение ролей | Нет массовых писем/блокировки аккаунтов |
| Admin справочников | Города, timezone, категории, активность | Поиск относительных дат пока в поясе первого города |
| Монетизация | Цены в БД, продукты, immutable order snapshot | Paid-продукты изначально выключены |
| Платёж и возврат | HMAC sandbox webhook и атомарные эффекты | Реальные провайдеры не реализованы |
| Пакеты/подписки | Срок и остаток прав размещений | Нет автопродления, скидок, премиальной аналитики |
| Аналитика | Views/favorites/contact clicks/share, агрегаты владельца | Не уникальные люди, не антифрод-аналитика |
| Worker | Очередь, lease, backoff, expiry, уведомления | Для 24/7 нужен отдельный исполнитель |
| SEO | Metadata, canonical, sitemap, robots, ограниченный JobPosting | Нет выдуманной hiringOrganization; разметка только при достаточных данных |
| Бесплатность | Нет обязательного платного API/SDK/шаблона | Free-tier лимиты и требования ПДн проверяет владелец |
| Production | Документация и исходники для испытаний | НЕ подтверждённый production-ready выпуск |

Будущие социальные функции, карта внутри сайта, геокодирование, отклики, отзывы и чат намеренно отсутствуют. Не показываются как работающие кнопки.
