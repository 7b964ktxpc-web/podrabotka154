Исходники MVP · версия 0.1

От архива к первому объявлению.

Короткий маршрут запуска. Код и подробные инструкции находятся в ZIP-архиве проекта.

Это инструкция, не запущенный сайт.

В архиве нет выдуманных вакансий. В среде подготовки прошли 42 unit-теста; полный запуск Next.js, Supabase и браузерная приёмка ещё обязательны.

0 из 6 шагов отмечено

01

Подготовить среду

Распакуйте ZIP на компьютере с Node.js 22.18+ и npm. Откройте README.md, затем SETUP.md. С телефона пока можно подготовить аккаунты.

Node.js ↗

02

Создать базу

Создайте новый Supabase-проект. Выполните миграции 001…008 по порядку, затем seed.sql: он содержит справочники, а не вакансии.

Открыть Supabase ↗

03

Настроить доступы

Скопируйте .env.example в .env.local и заполните серверные ключи. Для регистрации посетителей настройте SMTP и адреса возврата Supabase Auth.

Пароли и токены не отправляйте в чат.

04

Запустить сайт и worker

npm install
npm run typecheck
npm test
npm run dev

В другом терминале запустите npm run worker. Зарегистрируйтесь и назначьте первого администратора командой из SETUP.md.

05

Добавить реальное объявление

Ваш первый канал чужой: начните с ручного импорта оригинала через админку и ручной модерации. Автоматический приём ботом возможен только для каналов, куда его добавил владелец.

Что проверить перед публикацией

Реальность контактов и условий, право на публикацию текста, адрес и зарплату. Если информации нет, оставьте поле пустым. Не заполняйте его догадкой.

06

Пройти приёмку и разместить

Выполните QA.md: сборка, RLS, регистрация, поиск, избранное, карты и мобильный экран. Затем настройте хостинг и отдельное выполнение worker.
